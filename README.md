# ПДД 2026 — Полный курс

Мобильное web-приложение: 40 этапов, 800 видео, 280 вопросов, прогресс, разблокировка, статистика.

## 1. Установка Node.js
Скачай LTS-версию: https://nodejs.org

## 2. Установка зависимостей
```bash
npm install
npm run dev
```

## 3. Сборка
```bash
npm run build
npm run preview
```
